# haven-social-assets

Rendered image assets for Haven's weekly social posting automation.

**This repo is public for one reason:** Metricool's scheduling API fetches post
media over HTTP, so the images need a publicly reachable URL. Everything here is
a rendered marketing slide that is about to be posted publicly to Instagram or
TikTok anyway — nothing is exposed that wasn't already going public by design.

No application code, configuration, credentials, or user data belongs in this
repo. Haven's actual codebase lives in a separate private repository.

Images are generated by `marketing/automation/render-carousel.mjs` and organised
as `<YYYY-MM-DD>/slide-N.png` (carousels) or `<YYYY-MM-DD>/card.png` (single cards).
